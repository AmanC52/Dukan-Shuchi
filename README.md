# दुकान सहायक (Dukan Assistant Pro v2.0)
### स्मार्ट थोक खरीदारी, फुटकर बिक्री व मुनाफा प्रबंधक (Smart Purchasing, Inventory & Profit Manager)

यह टूल खास तौर पर भारतीय दुकानदारों व किराना स्टोर के लिए बनाया गया है, जिससे वे:
- **थोक मंडी/बाजार की खरीदारी की लिस्ट** पहले से तैयार कर सकें
- **थोक पेटी vs फुटकर पाउच/पीस (Sub-Quantity)** का सटीक हिसाब रख सकें (उदा. ₹1680 की 1 पेटी तेल में 12 पाउच, ₹160 प्रति पाउच फुटकर बिक्री = ₹240 शुद्ध मुनाफा प्रति पेटी)
- **तारीख-वार खरीदारी इतिहास (Trip History)** सुरक्षित कर सकें
- **लाइव खरीद लागत, संभावित बिक्री व शुद्ध मार्जिन** देख सकें
- **कैमरा बारकोड स्कैनर** से सामान स्कैन कर सकें
- **WhatsApp पर खरीदारी लिस्ट व बिल पर्ची** 1-क्लिक में शेयर या प्रिंट कर सकें
- **Windows .EXE ऐप** या **मोबाइल ऐप (PWA / Android APK)** के रूप में चला सकें

---

## 🚀 1. कंप्यूटर पर कैसे चलाएं? (Direct Windows Desktop App)

आपके लिए 3 बेहद आसान तरीके तैयार हैं:

### तरीका 1: सीधे डेस्कटॉप ऐप (.EXE)
- `dist/DukanSahayak/DukanSahayak.exe` पर डबल क्लिक करें।
- यह एक असली डेस्कटॉप सॉफ़्टवेयर की तरह अलग विंडो में खुलेगा (इसके लिए ब्राउज़र या टर्मिनल खोलने की ज़रूरत नहीं है)।
- *टिप:* आप `DukanSahayak.exe` पर राइट क्लिक करके **"Send to -> Desktop (create shortcut)"** कर सकते हैं, जिससे आपके कंप्यूटर स्क्रीन पर इसका शॉर्टकट बन जाएगा।

### तरीका 2: मुख्य फ़ोल्डर से 1-क्लिक लॉन्चर
- मुख्य फ़ोल्डर में मौजूद **`Dukan_Sahayak.bat`** पर डबल क्लिक करें।

### तरीका 3: बिना किसी ब्लैक स्क्रीन के शांत तरीके से खोलें
- फ़ोल्डर में मौजूद **`Dukan_Sahayak_Silent.vbs`** पर डबल क्लिक करें।

## 📱 2. मोबाइल पर कैसे चलाएं? (Mobile App - 2 तरीके)

### ⚡ तरीका A: तुरंत मोबाइल पर ऐप इंस्टॉल करें (PWA - 10 सेकंड में, बिना किसी झंझट के!)
यह सबसे तेज़ और आसान तरीका है। आपको कोई जटिल बिल्ड करने की ज़रूरत नहीं है:
1. आपका कंप्यूटर और आपका मोबाइल **एक ही वाई-फाई (Wi-Fi) या मोबाइल हॉटस्पॉट** से जुड़े होने चाहिए।
2. कंप्यूटर पर कमांड प्रॉम्प्ट में `ipconfig` देखें (उदा. आपका IP `192.168.1.15` है)।
3. अपने मोबाइल के Google Chrome ब्राउज़र में खोलें: `http://192.168.1.15:8000`
4. Chrome के ऊपर दाईं ओर **3 डॉट्स (⋮)** पर टैप करें।
5. **"Add to Home screen" (होम स्क्रीन पर जोड़ें) / "Install app"** पर क्लिक करें।
6. आपके मोबाइल की स्क्रीन पर **"दुकान सहायक"** का सुंदर ऐप आइकन बन जाएगा। यह बिल्कुल असली मोबाइल ऐप की तरह फुल स्क्रीन में खुलेगा और ऑफलाइन भी काम करेगा!

### 🌐 तरीका B: GitHub पर अपलोड करके Android APK (.apk) बनाना

हमने इस रिपॉजिटरी में **GitHub Actions ऑटोमैटिक APK बिल्डर** (`.github/workflows/build-apk.yml`) और **Capacitor** पहले से सेट कर दिया है।

#### GitHub पर कोड कैसे अपलोड करें:
1. GitHub (github.com) पर जाएं और एक नया रिपॉजिटरी बनाएं (उदा. `dukan-sahayak`).
2. अपने कंप्यूटर पर इस फ़ोल्डर में टर्मिनल खोलकर ये कमांड चलाएं:
   ```bash
   git init -b main
   git add .
   git commit -m "दुकान सहायक v2.0 - Complete Desktop and Mobile Ready"
   git remote add origin https://github.com/APNA_USERNAME/dukan-sahayak.git
   git push -u origin main
   ```
3. पुश करते ही GitHub पर **Actions** टैब अपने आप चालू हो जाएगा और Android APK बिल्ड करके आपको डाउनलोड के लिए दे देगा!

## 📦 3. थोक पेटी व सब-क्वांटिटी का हिसाब कैसे काम करता है?

जब आप कोई नया सामान जोड़ते हैं या पुराना एडिट करते हैं, तो आप यह भर सकते हैं:
- **थोक पैकिंग (Pack Unit):** जैसे `1 पेटी`
- **सब-क्वांटिटी (Sub-Quantity):** जैसे `12 पाउच`
- **1 पेटी थोक खरीद:** जैसे `₹1680`
- **फुटकर बिक्री भाव:** जैसे `₹160` प्रति पाउच

**सिस्टम अपने आप तुरंत कैलकुलेट करता है:**
1. $\text{प्रति पाउच खरीद लागत} = \frac{₹1680}{12} = ₹140$
2. $\text{प्रति पाउच मुनाफा} = ₹160 - ₹140 = ₹20$
3. $\text{1 पेटी पर कुल बिक्री} = 12 \times ₹160 = ₹1920$
4. $\text{1 पेटी पर कुल शुद्ध लाभ} = ₹1920 - ₹1680 = ₹240$ (12.5% मार्जिन)

## 💡 4. टूल को और बेहतर बनाने के 7 बेहतरीन आइडिया (Future Ideas)

1. **कैमरा बारकोड स्कैनर (Barcode Scanner):** *(मौजूदा वर्जन में शामिल)* मोबाइल या लैपटॉप कैमरे से सामान का बारकोड स्कैन करके तुरंत रेट देखना।
2. **व्हाट्सएप शेयर (WhatsApp Bill Share):** *(मौजूदा वर्जन में शामिल)* मंडी जाने से पहले थोक व्यापारी को या ग्राहक को 1 क्लिक में पर्ची व्हाट्सएप करना।
3. **उधार/खाता बही (Khata & Udhaar Register):** नियमित ग्राहकों और मंडी के व्यापारियों के लेन-देन का सरल हिसाब।
4. **कम स्टॉक चेतावनी (Low Stock Alert):** जो सामान खत्म होने वाला हो, वह खुद-ब-खुद लाल रंग में दिखे और खरीदारी लिस्ट में जुड़ जाए।
5. **यूपीआई क्यूआर कोड (Instant UPI QR Code):** बिल पर्ची पर आपकी दुकान का Google Pay / PhonePe QR कोड छपकर आना।
6. **एक्सपायरी डेट ट्रैकिंग (Expiry Alert):** नमकीन, बिस्किट, मसालों की एक्सपायरी से 15 दिन पहले चेतावनी।
7. **मंडी भाव तुलना (Price Tracker):** पिछली बार सामान कितने का आया था और इस बार कितने का मिल रहा है, इसका भाव में अंतर देखना।

## 🛡️ डेटा सुरक्षा व बैकअप (Data Safety)

- आपका डेटा पूरी तरह आपके कंप्यूटर में `data/dukan_data.db` में सुरक्षित रहता है।
- हर बार चालू होने पर `data/backups/` में टाइमस्टैम्प के साथ ऑटो-बैकअप सुरक्षित होता है।
- ऊपर हेडर में दिए गए **"बैकअप"** बटन से आप 1-क्लिक में कभी भी डेटाबेस डाउनलोड कर सकते हैं।
