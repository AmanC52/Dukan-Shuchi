## 📦 3. थोक पेटी व सब-क्वांटिटी का गणित

- **थोक पैकिंग (Pack Unit):** जैसे `1 पेटी`
- **सब-क्वांटिटी (Sub-Quantity):** जैसे `12 पाउच`
- **1 पेटी थोक खरीद:** जैसे `₹1680`
- **फुटकर बिक्री भाव:** जैसे `₹160` प्रति पाउच

**सिस्टम अपने आप तुरंत कैलकुलेट करता है:**
1. $\text{प्रति पाउच खरीद लागत} = \frac{₹1680}{12} = ₹140$
2. $\text{प्रति पाउच मुनाफा} = ₹160 - ₹140 = ₹20$
3. $\text{1 पेटी पर कुल बिक्री} = 12 \times ₹160 = ₹1920$
4. $\text{1 पेटी पर कुल शुद्ध लाभ} = ₹1920 - ₹1680 = ₹240$ (12.5% मार्जिन)

- ऊपर हेडर में दिए गए **"बैकअप"** बटन से आप 1-क्लिक में कभी भी डेटाबेस डाउनलोड कर सकते हैं।
